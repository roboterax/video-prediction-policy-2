# README link badges

Static SVG badges used by the repository README. Platform icon paths come from
[Simple Icons](https://github.com/simple-icons/simple-icons), under its
[CC0 license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md):

- [arXiv](https://github.com/simple-icons/simple-icons/blob/develop/icons/arxiv.svg)
- [ModelScope](https://github.com/simple-icons/simple-icons/blob/develop/icons/modelscope.svg)
- [Hugging Face](https://github.com/simple-icons/simple-icons/blob/develop/icons/huggingface.svg)

The globe and badge layout are drawn for this repository. Platform paths are
preserved; only presentation color and size are set by the badge.
